# {{APP_NAME}}

Generated by `mre new`. See [the framework docs](https://github.com/Shrawan-13/mre/tree/main/docs) for the Lua API.

## Develop

```bash
mre dev
```

Scan the QR with the MRE dev client APK. Edit `src/main.lua` and save: the
phone updates without rebuilding the APK. Values created with
`mre.persist(key, initial)` survive a reload; everything else starts fresh.

## Build

```bash
mre build android          # dev client (QR pairing)
mre build android --prod   # release APK with Lua baked in
```

## Layout

```
mre.toml          project manifest
src/main.lua      app entry point
framework/        Lua-only theme / widget overrides
assets/           static files
tests/            Lua smoke tests
plugins/          optional native plugins (`mre plugin new <name>`)
android/          Gradle template; generated, don't hand-edit
```
